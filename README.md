# Project Bromania MMXXVII

Five guys. Dulles → Istanbul → a night train to Sofia → Transylvania. **15–25 Sep 2027.**

This is the planning HQ: the week, the bookings, the bags.

## The trip

- Fly Turkish ExtraFly out of Dulles 14 Sep (TK8, 9:40pm if it still exists)
- Three nights in Karaköy
- Saturday 18 Sep: Istanbul–Sofia night train (no restaurant — pack food), then a van into Romania
- Brașov as base: Bran (the photo), Poenari (1,480 steps, the real citadel), salt mine + Peleș
- Home from Bucharest 25 Sep on the same Turkish ticket

One person holds the card. Everyone else: passport, one bag, show up.

## Run it

```bash
npm install
npm run dev
```

Opens on port 8080.
